Bridge

This tab holds the connection to the bridge on your machine. The agent's tools run here, and the socket lives as long as this tab exists.

Leave it open. It is pinned, so it stays visible at the front of the tab bar. Closing it is allowed — it comes back by itself, and the connection with it.

What is wrong when nothing connects: about:debugging → this extension → “Inspect”, for the endpoint and the token in the options.
