The bridge's endpoint and the same token as on the server. The endpoint is pre-filled; without a token the extension deliberately does not connect.

Change this URL only if the bridge runs on another machine — then enter that machine's address; for the public route through Caddy use the wss:// URL from INSTALL.md §9.

While this is off, the agent refuses every field with type="password" without writing into it. The value is read on every call, so a change takes effect immediately.

While this is on, the agent may run arbitrary code in the page context. The code then reaches the same data as the page itself, including document.cookie (but not HttpOnly cookies), localStorage and fetch with this profile's cookies. It may change the page and lifts the lock on password fields. Since the code runs in the page's own world, it also sees that page's variables — everything a script on the page itself could read. Code that never returns can freeze the tab; only closing the tab helps then. The value is read on every call, so a change takes effect immediately.

While this is off, the agent refuses every capture. While it is on, it sees the visible part of the agent tab as an image — exactly what is on screen: the logged-in profile with its mailbox, shopping cart or account data. Hidden tabs and other windows are not in the picture. The value is read on every call, so a change takes effect immediately.
